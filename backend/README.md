# Solfa Scan API

FastAPI and PaddleOCR backend for layout-aware tonic solfa scans.

The GitHub repository is the source of truth. The `Deploy backend to Hugging Face`
workflow mirrors this directory into the public Docker Space. Uploaded documents,
scan jobs and corrections are temporary and are cleared when the Space restarts.
